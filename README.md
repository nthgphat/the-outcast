# About
The Outcast, a 2-dimensional turn-based RPG.

## Features
- 2-dimensional turn-based combat, 1v1, the player vs 1 enemy.
- 4 levels, featuring 3 enemies and 1 boss with various stat differences.
- Player gain EXP from completing levels.
- Player can use EXP to level up.
- Player can equip armor & weapons, which increases their stats.
- During combat, the player can choose between actions, some of which are:
	+ Do nothing.
	+ Basic attack that deals damage equal to 100% of the player's attack power.
	+ Heal 50%, which heals the player for 50% of their maximum health. This action has a cooldown of 3 turns.

## Usage
Download Godot & load this project.
